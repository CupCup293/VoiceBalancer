# VoiceBalance 1.2.0

Пользовательский плагин Vencord для Vesktop и браузера. Обрабатывает входящий звук каждого собеседника локально и сохраняет штатные настройки громкости и отключения звука.

## Установка

Архив плагина доступен на странице [GitHub Releases](https://github.com/CupCup293/VoiceBalancer/releases).

1. Удали предыдущую копию VoiceBalance из `src/userplugins`, если она есть.
2. Скопируй папку `voiceBalance.web` в `src/userplugins` исходников Vencord. Точка входа должна оказаться по пути `src/userplugins/voiceBalance.web/index.tsx`.
3. Пересобери Vencord через `pnpm build` для Vesktop или `pnpm buildWeb` для браузера.
4. Перезапусти клиент, отключи VolumeBooster, если он включён, и включи VoiceBalance в разделе плагинов Vencord.

[Инструкция Vencord по пользовательским плагинам](https://docs.vencord.dev/installing/custom-plugins/)

## Настройки

- **Баланс звука** задаёт целевую громкость всех собеседников. Чем ближе значение к нулю, тем громче.
- **Сила выравнивания** позволяет выбрать мягкое, обычное или усиленное выравнивание либо отключить его. Шумоподавление настраивается отдельно.
- **Громкость VoiceBalance** в меню собеседника сдвигает его целевой уровень на ±3 или ±6 дБ. Настройка сохраняется между звонками и действует при включённом выравнивании.
- **Шумоподавление для всех** задаёт настройку по умолчанию. В меню собеседника выбери **Шумоподавление VoiceBalance** → **Включено**, **Выключено** или **Как в общих настройках**. Индивидуальная настройка имеет приоритет и сохраняется между звонками.
- **Сила шумоподавления** позволяет выбрать обычный режим или сильную изоляцию. Сильная изоляция может приглушать шёпот и окончания слов.

Баланс остаётся активным при выключенном шумоподавлении. Плагин держит оценку громкости в коротких паузах, ограничивает пики отдельно и плавно переключается между исходным и очищенным сигналом. RNNoise запускается только при необходимости. Если браузер блокирует AudioWorklet, остаётся базовое выравнивание. Официальный настольный Discord использует другой голосовой движок.
